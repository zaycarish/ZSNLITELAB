# ZSNLITELAB
Documentation of my self-hosted Ubuntu Linux homelab, including Docker & Jellyfin, networking, media services, troubleshooting, and system administration.

Welcome to my personal home {homelab} documentation repository.

ZSNLITELAB is a self-hosted infrastructure environment built using repurposed Dell hardware.
The computer originally came from my girlfriend, who obtained it through her workplace after the company upgraded its equipment to support a new system. Rather than disposing of its older hardware, the company sold the computers at a fraction of their original cost.
The machine originally ran Windows 10 Professional. My initial goal was relatively simple: create a personal Jellyfin media server where I could digitize my existing DVD collection and stream it across my devices.
However, I encountered several challenges while setting up Jellyfin on Windows. These difficulties ultimately led me to migrate the system to Ubuntu Linux, opening the door to a much larger project.
What began as a simple media server gradually evolved into a fully functioning personal homelab, hosting multiple containerized applications and network services.
Today, I use ZSNLITELAB to develop practical experience in Linux system administration, networking, Docker containerization, storage management, remote access, and IT troubleshooting.
This repository documents the infrastructure I've built, the technical challenges I've encountered, the solutions I've implemented, and the knowledge I've gained along the way.
